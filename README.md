# Clipboard Landing Page

A responsive landing page built with HTML and CSS from the provided Clipboard design.

## Overview

This project recreates the supplied desktop and mobile layouts while keeping the page responsive from small mobile screens to large desktops.

## Built with

- Semantic HTML5
- CSS custom properties
- Flexbox
- CSS Grid
- Responsive media queries
- Mobile-first styling

## Features

- Responsive layout for mobile and desktop
- Hover and keyboard-focus states for interactive elements
- Semantic page structure
- Meaningful alternative text for content images
- Reuses the optimized assets supplied with the assignment
- No JavaScript or CSS framework required

## Project structure

```text
clipboard-landing-page-master/
├── images/
├── design/
├── index.html
├── style.css
├── style-guide.md
└── README.md
```

## Running the project

Open `index.html` in a browser, or use the Live Server extension in VS Code.

## What I learned

This project helped me practice turning a visual design into semantic HTML, building responsive layouts with Flexbox and CSS Grid, using media queries, and organizing CSS with clear class names.

## Notes

The `images/` and `design/` folders are the original assets supplied with the assignment.
