## What I Learned

- How to use CSS custom properties for consistent theming
- Building a two-column layout with Flexbox
- Mobile-first approach with a single `@media` query
- Using `clamp()` for responsive font sizing without breakpoints
- How `filter: grayscale()` and hover color transitions work on images

## What I Found Challenging

- Getting the computer image to bleed off the left edge (`margin-left: -2rem`) while keeping the layout clean
- Making the footer stay in a clean 3-column row on desktop but stack properly on mobile
- Matching the teal hover color on SVG icons using CSS `filter` chains

## How to Run Locally

```bash

# open index.html in your browser — no build step needed
```
